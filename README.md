# Modern Portfolio Site

A professional portfolio website built with React, TypeScript, and Chakra UI, featuring smooth animations with Framer Motion.

![Portfolio Screenshot](https://via.placeholder.com/800x400?text=Portfolio+Screenshot)

## 🚀 Features

- **Modern React**: Built with React 18 and TypeScript for type-safe code
- **Beautiful UI**: Polished design using Chakra UI component library
- **Dark/Light Mode**: Seamless theme switching for user preference
- **Smooth Animations**: Engaging transitions powered by Framer Motion
- **Fully Responsive**: Optimized for all device sizes
- **Accessible**: Built with a11y best practices in mind
- **Contact Form**: Ready-to-connect form with validation
- **SEO Friendly**: Optimized meta tags and performance
- **Fast Loading**: Optimized with lazy-loading and code-splitting

## 📋 Prerequisites

- Node.js (v14.0.0 or higher)
- npm or yarn

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Portfolio-Site.git
cd Portfolio-Site
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📁 Project Structure

```
/src
  /components         # Reusable UI components
  /data               # Portfolio data and content
  /hooks              # Custom React hooks
  /theme              # Chakra UI theme configuration
  /types              # TypeScript type definitions
  App.tsx             # Main application component
  main.tsx            # Application entry point
```

## 📊 Performance Optimization

This portfolio site implements several performance optimization techniques:
- Code splitting with React.lazy and Suspense
- Optimized animations with Framer Motion
- Image optimization
- Efficient rendering with React

## 🔧 Customization

To customize this portfolio for your own use:

1. Update personal information in `/src/data/portfolio-data.ts`
2. Replace project images in `/public/projects/`
3. Modify theme colors in `/src/theme/`
4. Connect the contact form to your preferred backend service
